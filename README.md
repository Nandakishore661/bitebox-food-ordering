# 🍴 BiteBox – Food Ordering Website

BiteBox is a modern, responsive food ordering frontend built using **HTML, CSS, and JavaScript**. It provides a smooth food browsing and ordering experience with an interactive shopping cart, checkout form, and order tracking dashboard.

## ✨ Features

- 🍕 Dynamic food menu with food images and prices
- 🔎 Search functionality and category filtering
- ↕️ Sort food by price and rating
- 🛒 Add to cart, update quantities, and remove items
- 💰 Automatic subtotal, delivery fee, tax, and total calculation
- 🧾 Checkout form with customer and delivery details
- 🆔 Unique order ID generation
- 🚚 Order tracking timeline with four delivery stages
- 💾 Cart and order persistence using browser localStorage
- 📱 Responsive design for mobile, tablet, and desktop

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Browser localStorage

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using the Live Server extension.
4. Browse the menu, add items to your cart, and complete the demo checkout.
5. Use the generated order ID to test the order tracking feature.

## ⚠️ Project Note

This is a frontend demonstration project. Checkout, payment options, and delivery tracking are simulated in the browser. Real payments, GPS tracking, and multi-user order synchronization require a backend and appropriate integrations.
